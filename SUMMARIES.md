# Paper Summaries

One- or two-sentence plain-language summaries used for retrieval, newest first. Each is
written for a researcher who knows robot learning but has only a little background in
LLM agents. Full metadata — labels, venue, year, affiliation, and
links — lives in the [README table](README.md); your own opinions and longer notes live
one-file-per-paper in [notes/](notes/).

- **Reconstruct, Practice, Go Real: Guided Self-Improvement for Embodied Agents** ([paper](https://arxiv.org/abs/2610.02204)) — LLM agents rebuild tasks from an offline robot dataset as simulation practice environments, then practise there in rounds: after each round an agent compares failed runs with the dataset videos and the simulator's ground truth, and rewrites the skill code and instructions that a code-writing agent uses at run time. Success on 22 simulated tasks rises from 28.6% to 95.0% over 15 rounds, and the frozen system then succeeds in all 30 real-robot trials.
- **SimEX: Simulation-Integrated Robotics AutoResearch** ([paper](https://arxiv.org/abs/2609.38982)) — Lets a coding agent rebuild the robot's workspace in simulation and experiment there freely to develop a toolbox of perception and control routines, then uses a few real trials to correct both the simulator and the toolbox. With no demonstrations and only 10 minutes of real-robot interaction, it learns towel folding, barcode scanning and plate handling on a real two-arm robot.
- **Find Something You Can't Do: Agentic Real-World Reinforcement Learning for Self-Improving VLA Models** ([paper](https://arxiv.org/abs/2609.32069)) — Lets a real robot practise on its own: after each attempt a VLM looks at the scene, picks a task from a fixed list that is feasible now and that the robot is currently bad at, and judges success from before/after images, which serves as the reward for RL on top of a frozen VLA. Over six hours and 456 unattended episodes, success across eight tasks rises from 55% to 71.9% with no human reward labels.
- **RAPID: Robot Agentic Programming from Demonstrations** ([paper](https://arxiv.org/abs/2609.30249)) — From a single human video, a coding agent works out what the task requires, rebuilds the scene in simulation, and writes and tests a robot program there until it passes. The program is built from trajectory-optimization steps tied to objects rather than fixed motions, so it carries over to new poses, shapes and materials, and it runs on a real Franka arm on eight tasks that move objects without grasping them.
- **Generalizing Manipulation Skills with a Local Coding Agent** ([paper](https://arxiv.org/abs/2609.26499)) — Runs an open-weight VLM on a single workstation as a coding agent that reads a human-written step-by-step task description, then writes and runs its own perception and motion code on a real UR3e arm, checking each step and retrying when it fails. It carried tasks over to new object colours, sizes and shapes in 30 of 45 trials, though a trial takes 3 to 68 minutes.
- **Coding Agents with an Obstacle-Aware Harness for Safe Robot Manipulation** ([paper](https://arxiv.org/abs/2609.20822)) — Gives a coding agent that writes robot controllers two obstacle-aware helpers: one plans a waypoint route that is checked against the obstacle and replanned if it fails, the other picks a contact point that keeps the arm clear. On a simulated safety benchmark this reaches 71.9% task success and 87.5% collision avoidance, 2.3 and 1.5 times the same agent without the helpers.
- **Agent as Policy for Robotic Manipulation** ([paper](https://arxiv.org/abs/2609.12541)) — Lets a general-purpose coding agent act as the robot policy with no task-specific training: while the robot works, the agent looks at camera images, writes and runs programs that send motion commands, and revises them after seeing what physically happened. It reaches at least 80% success in seven of eight real-world task setups, including assembly, throwing and two-arm towel folding, though a trial takes tens of minutes.
- **Show-Harness: Just a VLM Agent Can Play Robots** ([paper](https://arxiv.org/abs/2609.10522)) — Lets a general VLM control a robot directly by choosing small named motion steps (move, rotate, grip) that a fixed interpreter turns into robot commands, with add-ons for subtask planning and grasp-failure recovery. A frontier VLM works zero-shot through this interface on two real robots, and a 2B open model fine-tuned for a few GPU-hours on the same interface comes close to it.
- **Revisiting the "Push-T" Robot Manipulation Task with Agentic Robotics** ([paper](https://arxiv.org/abs/2608.18227)) — Asks a coding agent (Claude Code) to solve the Push-T benchmark by writing the controller as ordinary code with no demonstrations: the agent runs simulation experiments, studies the failures and rewrites the controller over many rounds, so no LLM runs during control. The final controller reaches 100% success in simulation using 46% fewer steps than the best diffusion policy trained on 200 human demonstrations.
- **Addressing the Orchestration Gap in Generalist Robots via Physical Agency** ([paper](https://arxiv.org/abs/2607.21725)) — Wraps a frozen VLA and a grasp planner as tools for a frontier VLM that plans subgoals, checks each outcome from sensors and images, and retries on failure, with no extra training. This lifts LIBERO-PRO success from 12.8% to 53.3%, and takes a real Franka from near zero to over 90% on tasks that need reasoning.
- **Agentic Real2Sim: Physics-based World Modeling with Vision-Language Agents** ([paper](https://arxiv.org/abs/2607.19190)) — Uses VLM agents to turn a real recording of a robot handling objects into a runnable physics simulation: the agents call perception tools to recover geometry and poses, estimate mass and material, assemble the scene, and fix what the checks flag. The converted episodes can generate fine-tuning data and stand in for real-world policy evaluation, and an open-weight VLM does the job at a fraction of a frontier model's cost.
- **RoboHarness: Memory-Driven Orchestration of Heterogeneous Robot Policies for Long-Horizon Planning** ([paper](https://arxiv.org/abs/2607.18060)) — Wraps independently built policies (VLAs, world-action models, RL policies, motion planners) as skills for a coding agent that splits a long task and routes each part to the policy that past experience shows can handle it. A memory of successful runs is also used at each handoff to move the robot into a state the next policy is familiar with.
- **VIA: Visual Interface Agent for Robot Control** ([paper](https://arxiv.org/abs/2607.11119)) — Has an off-the-shelf coding agent (Claude Code or Codex) operate a robot arm the way it would operate software: it looks at screenshots of a browser-based 3D view, sets a target gripper pose through a few tools, watches the result and adjusts. With no robot-specific training it reaches 96.7% on three LIBERO-Goal tasks and solves a long block-assembly task, all in simulation.
- **Harness VLA: Steering Frozen VLAs into Reliable Manipulation Primitives via Memory-Guided Agents** ([paper](https://arxiv.org/abs/2607.08448)) — Keeps a pretrained VLA frozen and uses it only for the contact-rich part of a task, while an LLM agent handles everything around it: choosing the target, moving the arm into position with scripted primitives, and retrying after a failed grasp. A memory of past successes and failures teaches the agent where the VLA works, giving gains of 38.6 points on LIBERO-Pro and 25.4 on RoboCasa365 over the best baselines.
- **GaP: A Graph-as-Policy Multi-Agent Self-Learning Harness For Variational Automation Tasks** ([paper](https://arxiv.org/abs/2607.05369)) — For industrial-style tasks with varied objects, LLM agents assemble the policy as a graph of perception, planning and control modules from a skill library, then build a simulation of the task and rehearse many graph variants in parallel to fix failures. The resulting graphs clearly outperform VLA and planning baselines on four simulated and four real-world tasks such as grocery packing and cable insertion.
- **ASPIRE: Agentic /Skills Discovery for Robotics** ([paper](https://arxiv.org/abs/2607.00272)) — A coding agent writes robot control programs, reads detailed execution traces to diagnose failures, repairs the code, and stores each validated fix in a skill library that later tasks reuse; an evolutionary search proposes new tasks and program variants to keep exploring. The library carries over to unseen long tasks (31% against 4% for earlier methods on LIBERO-Pro Long) and shows first signs of transfer to real robots.
- **ENPIRE: Agentic Robot Policy Self-Improvement in the Real World** ([paper](https://arxiv.org/abs/2606.19980)) — Sets up a loop on real robots that resets the scene, runs the policy, checks the outcome and trains again, so coding agents can improve a learned policy without a human present. Between rollouts the agents read logs and videos and rewrite the success checks, reset routines and training code, reaching a 99% success rate on dexterous tasks such as organizing a pin box and fastening a zip tie.
- **Playful Agentic Robot Learning** ([paper](https://arxiv.org/abs/2606.19419)) — Lets a coding agent "play" before any real task arrives: it invents practice tasks that are new but achievable, writes robot code to attempt them, diagnoses failures and retries, and saves the programs that worked into a reusable skill library. Reusing those skills on unseen simulated tasks raises success by 20.6 points on LIBERO-PRO and 17.0 on MolmoSpaces over a strong code-writing baseline.
- **Guava: Distilling Frontier VLMs into a Compact Agent through a Robotic Manipulation Harness** ([paper](https://arxiv.org/abs/2606.18363)) — Studies what interface a VLM needs to control a robot through tool calls (a perceive-reason-act loop, named motion tools, image plus state observations), then uses a frontier VLM's simulated runs through that interface to fine-tune a 4B open model. With fewer than 2K trajectories the small model performs close to the frontier model in simulation and on a real Franka, at much lower latency.
- **RHO: Your Coding Agent is Secretly a Roboticist** ([paper](https://arxiv.org/abs/2606.16458)) — Uses a coding agent to evolve a whole multi-file policy codebase before deployment: it edits the code, runs it in simulation, and uses rewards and execution errors to guide the next edit, with no demonstrations. The finished code runs with no LLM in the loop and reaches 70.0% on Robosuite and 45.0% on LIBERO-PRO, 2.5 times the best agent that rewrites code during execution.
- **What Matters in Orchestrating Robot Policies: A Systematic Study of Hierarchical VLA Agents** ([paper](https://arxiv.org/abs/2606.10267)) — A controlled study of systems where a VLM planner hands language subgoals to a VLA, testing which design choices matter: the planner's reasoning ability, how steerable the VLA is, how a subgoal is ended, how observations are described, and what memory is kept. A reasoning-capable planner and a steerable VLA matter most, and a hierarchy built on these findings beats both a plain VLA and a naive hierarchy in simulation and on a real ALOHA robot.
- **HARBOR: A Harness Framework for Agentic Robot Reinforcement Learning** ([paper](https://arxiv.org/abs/2606.08610)) — Splits the RL-in-simulation workflow into stages run by specialised coding agents: setting up the task, writing the reward, choosing domain randomization and tuning the algorithm, with checks between stages and a store of what worked in earlier runs. It automates the pipeline end to end on 16 tasks across 6 simulators, including two-handed dexterous control, and the resulting policies can be transferred to real robots.
- **VoLo: A Physical Orchestrator for Open-Vocabulary Long-Horizon Manipulation** ([paper](https://arxiv.org/abs/2606.07723)) — A VLM runs alongside the robot as an orchestrator: it calls a VLA, vision models and motion primitives as tools, keeps watching while they run, and can interrupt the VLA mid-motion to switch tools or recover. On a new benchmark of open-ended long tasks and on a real Franka it does about three times better than the VLA alone.
- **RDA: Reward Design Agent for Reinforcement Learning** ([paper](https://arxiv.org/abs/2606.01672)) — An agent writes the RL reward function as code and revises it after each training run, but instead of reading only success rates it has a VLM watch rollout videos, check each subtask and name the failure before editing. The resulting policies follow the task instructions more faithfully than Eureka's at similar success rates on 16 ManiSkill and HumanoidBench tasks.
- **From Reaction to Anticipation: Proactive Failure Recovery through Agentic Task Graph for Robotic Manipulation** ([paper](https://arxiv.org/abs/2605.11951)) — Before the robot moves, LLM agents write the task as a graph of steps, add recovery branches for the failures they anticipate, and compile it into code with lightweight monitors. When a monitor trips during execution the robot jumps straight to the prepared recovery instead of pausing to re-plan, which improves success and shortens execution on real two-arm tasks.
- **CaP-X: A Framework for Benchmarking and Improving Coding Agents for Robot Manipulation** ([paper](https://arxiv.org/abs/2603.22435)) — An open benchmark and toolkit for agents that control robots by writing code: it tests 12 frontier models at different levels of hand-built abstraction and shows they lean heavily on human-designed helper functions. Adding multi-turn feedback, text descriptions of image changes and automatically written skills closes much of that gap, giving a training-free agent that reaches human-level reliability on several tasks in simulation and on real robots.
- **RoboClaw: An Agentic Framework for Scalable Long-Horizon Robotic Tasks** ([paper](https://arxiv.org/abs/2603.11558)) — Puts one VLM agent in charge of both collecting training data and running a robot's learned VLA skills: each skill is paired with an "undo" skill so the robot resets the scene itself, and at deployment the agent chooses which skill to run next and recovers from failures. On real long-horizon tasks it raises success by 25% over baseline pipelines and cuts human time by 53.7%.
- **Uni-Skill: Building Self-Evolving Skill Repository for Generalizable Robotic Manipulation** ([paper](https://arxiv.org/abs/2603.02623)) — A VLM planner writes policy code from a skill library and, when no existing skill fits, requests a new one, which is implemented from examples retrieved out of a large library of automatically annotated robot videos. The skill set therefore grows without manual work, and the system beats earlier VLM skill-based methods on unseen tasks in simulation and on a real Franka.
- **SceneSmith: Agentic Generation of Simulation-Ready Indoor Scenes** ([paper](https://arxiv.org/abs/2602.09153)) — Generates cluttered, physically valid indoor scenes for robot simulation from a text prompt, using three VLM agents (a designer that places objects, a critic that scores the result, an orchestrator that decides when to redo) plus text-to-3D generation for the objects. Scenes hold 3-6 times more objects than earlier methods with under 2% collisions, and can be used to evaluate robot policies automatically.
- **VLS: Steering Pretrained Robot Policies via Vision-Language Models** ([paper](https://arxiv.org/abs/2602.03973)) — Adapts a frozen diffusion or flow policy at test time without retraining: a VLM looks at the new scene and writes differentiable reward functions for each stage of the task, whose gradients nudge the policy's action sampling toward the new requirement, such as avoiding an obstacle or reaching a moved target. It improves on earlier steering methods by 31% on CALVIN and 13% on LIBERO-PRO and works on a real Franka.
- **Towards Reliable Code-as-Policies: A Neuro-Symbolic Framework for Embodied Task Planning** ([paper](https://arxiv.org/abs/2510.21302)) — Makes LLM-written robot code more reliable in two steps: a logic solver checks the code against a formal task specification, and steps the model is unsure about trigger short exploratory actions that gather the missing observations first. This raises task success by 46.2% over Code-as-Policies baselines on RLBench and in real-world tests where the scene changes or is only partly visible.
- **Gemini Robotics 1.5: Pushing the Frontier of Generalist Robots with Advanced Embodied Reasoning, Thinking, and Motion Transfer** ([paper](https://arxiv.org/abs/2510.03342)) — Pairs a VLA that reasons in language before acting with a separate embodied-reasoning VLM used as an orchestrator: it breaks a long task into steps, calls the VLA and tools such as web search, and checks progress to decide when to move on or re-plan. On long multi-step real-robot tasks the combined agent reaches progress scores of up to about 80%, where the VLA alone tops out at 44%.
- **HumanoidGen: Data Generation for Bimanual Dexterous Manipulation via LLM Reasoning** ([paper](https://arxiv.org/abs/2507.00833)) — Generates simulated demonstrations for a humanoid with two dexterous hands: an LLM writes each task's scene setup and a chain of spatial constraints between hands and objects, a solver turns the constraints into motion, and a tree search helps on long tasks. Diffusion policies trained on the generated data keep improving as the dataset grows across 20 two-handed tasks.
